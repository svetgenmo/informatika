Печать: Ctrl+P → ориентация альбомная, масштаб 100 % (не «вписать в лист»), поля нет, «печать фона» включить — иначе пропадут рамки таблиц. На листе две одинаковые карточки: разрезать по пунктиру посередине, получится две штуки формата A5. Эта серая рамка на бумагу не печатается.

Вторая пара углублённого курса: компиляция и интерпретация, байт-код и виртуальная машина, трассировочная таблица и три сломанные программы

Кто стоит между программой и процессором

компиляторинтерпретатор
когда переводитвсю заранее, до запуска по ходу, строка за строкой
что остаётсяготовый файл (.exe) ничего, результат сразу
когда видно ошибкудо запуска, все сразу когда до неё дошло выполнение
языкиC, C++, PascalPython, JavaScript

У Python дорога длиннее: текст переводится в байт-код (папка __pycache__), а выполняет его виртуальная машина. Байт-код одинаков везде, машины написаны под каждую систему — поэтому программа переезжает с Windows на Linux без единой правки. Плата — скорость. Так же устроены Java (JVM) и C# (.NET).

Две разные беды, и лечатся по-разному

не запускаетсякрасный текст, SyntaxError, ValueError — читать последнюю строку сообщения: там что и где
работает, но врётошибок нет, ответ неправильный — трассировка, отладочный вывод, отладчик

Три инструмента

  1. Трассировочная таблица — переменные в столбцы, цикл проходится руками. Самый дешёвый и часто самый быстрый.
  2. Отладочный вывод — временный print там, где надо увидеть, что происходит. Убрать перед сдачей: забытая строка — уже другой ответ.
  3. Отладчик — показывает значения переменных и путь программы. Ошибку он не находит и не исправляет: вывод делаешь ты.

Отладчик IDLE за шесть шагов

  1. перейти в главное окно IDLE — то, где >>>;
  2. Debug → Debugger, в Shell появится [DEBUG ON];
  3. поставить галочки Locals и Globals — иначе значений не увидишь;
  4. вернуться в окно программы, F5 — встанет на первой строке;
  5. Step — шаг, Over — не заходя в функцию, Out — выйти из функции, Go — до точки останова, Quit — прервать;
  6. закончил — выключить тем же пунктом меню.

Точка останова: правой кнопкой по строке → Set Breakpoint, строка станет жёлтой. Go домчит до неё и остановится. В цикле незаменима — не нужно жать Step по сто раз.

Программа зависла

Ctrl+C в окне Shell: Python напечатает KeyboardInterrupt и покажет строку, на которой прервали, — она внутри вечного цикла. Дальше смотреть переменную из условия цикла: меняется ли она внутри? Не меняется — условие останется истинным навсегда.
