Часть 2. Как устроена функция

def, параметры, return

def только запоминает функцию — ничего не считает. Считать она начинает при вызове: аргументы по порядку встают в параметры, строки тела выполняются, return отдаёт значение туда, где стоял вызов.

Процедура и функция

ПроцедураФункция
что делаетчто-то делает: печатает, рисует что-то считает и отдаёт через return
что возвращаетNone — «ничего»число, True/False…
как зовутотдельной строкой: show(5) внутри выражения: y = f(5) + 1, if is_prime(n):

В Python обе пишутся через def; разница только в return. В заданиях практикума функции обязаны возвращать: напечатанное нельзя сложить, сравнить или поставить в if.

Свои имена у каждой функции

  • Параметры и всё, что создано внутри функции, — локальные: снаружи их нет (NameError).
  • В параметр приходит копия числа: изменить внешнюю переменную так нельзя. Нужно новое значение — m = inc(m).
  • Чего нет внутри, функция ищет снаружи — и берёт таким, каким оно стало к моменту вызова. Надёжнее всё нужное передавать параметрами.

return обрывает функцию сразу

«Нашёл — ответил» пишется return внутри цикла, а «не нашёл» — после цикла. Поставить return True в else внутри цикла — частая ошибка: функция ответит на первом же витке.

Функция-признак и функция из функций

Функция, которая отвечает True или False, — признак: if is_prime(x): читается как фраза. Строка в тройных кавычках первой строкой тела — документация: help(nod) покажет её так же, как у math.isqrt.

Где что стоит в программе

  1. Сначала все def — функцию нельзя позвать выше её определения (NameError).
  2. Потом основная программа: ввод, циклы с вызовами, вывод.
  3. Число аргументов в вызове равно числу параметров, иначе TypeError.

Подсказка: подпрограммы

Функция

def имя(параметры): — тело — return значение. def только запоминает функцию, считает она при вызове. Аргументы встают в параметры по порядку: f(7, 2) в def f(a, b) даёт a = 7, b = 2.

Процедура и функция

Процедура делает (печатает), функция считает и отдаёт через return. Без return функция отдаёт None: print(show(4)) напечатает то, что печатает show, а потом None. К None нельзя прибавить число.

Локальные имена

Параметры и переменные, созданные внутри, живут только внутри функции. В параметр приходит копия числа: внешняя переменная не меняется. Нужно новое значение — m = inc(m).

return

Сразу выходит из функции, даже из середины цикла. «Нашёл — return» внутри цикла, «не нашёл — return» после цикла. Строки после return не выполняются.

Признак и функция из функций

Признак возвращает True или False и стоит прямо в if: if is_prime(x):. Одна функция может звать другую: nok(a, b) = a // nod(a, b) * b.

Порядок в программе

Сначала все def, потом основная программа. Вызов выше def — NameError; не то число аргументов — TypeError. """Строка документации""" первой строкой функции — её показывает help().
