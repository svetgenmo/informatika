Кусок программы получает имя, вход и выход — и дальше его зовут, а не переписывают. 10 класс, углублённый уровень — занятие десятое.

Сегодня делаем так же со своими кусками: сумма цифр, «простое ли число», НОД — пишем один раз и дальше просто зовём.

def: имя, параметры, return

def area(w, h):
    s = w * h
    return s

print(area(3, 5))

area — имя, w и h — параметры (вход), return s — выход.

def только запоминает функцию — ничего не считает. Считать она начнёт при вызове.

Вызов area(3, 5): аргументы 3 и 5 по порядку встают в параметры — w = 3, h = 5. return отдаёт 15 туда, где стоял вызов.

return отдаёт значение в выражение

x = area(2, 4) + 1          # 8 + 1 = 9
if area(3, 3) > 5:          # 9 > 5 — да
    print("большая")
print(area(area(1, 2), 3))  # сначала area(1, 2) = 2, потом area(2, 3) = 6
Вызов функции — это просто значение. Его можно сложить, сравнить, передать в другой вызов.

Вызов внутри вызова считается первым: сначала аргументы, потом сама функция.

В Python обе пишутся через def. Разница — только в return.

Откуда берётся None

def show(x):
    print(x * 2)

r = show(4)
print(r)
print(r + 1)

На экране 8 — это печатает сама show.

Потом None: return нет, и функция отдаёт «ничего». Его и положили в r.
r + 1 — TypeError: к None число не прибавить. Напечатанное нельзя использовать дальше — поэтому считающая функция возвращает, а не печатает.

У каждой функции свои имена

x = 5
def f(x):
    x = x * 2
    return x

y = f(x)
print(x, y)

Внутри f своё x — параметр. Его удвоили, а внешнее x осталось 5. На экране 5 10.

Параметры и всё, что создано внутри, — локальные: снаружи их нет, NameError.

В параметр приходит копия числа. Нужно новое значение снаружи — забери его: m = inc(m).

return обрывает функцию сразу

def is_prime(n):
    if n < 2:
        return False
    d = 2
    while d * d <= n:
        if n % d == 0:
            return False
        d = d + 1
    return True

Нашёлся делитель — ответ уже ясен: return False, и цикл дальше не крутится.

«Нашёл» — return внутри цикла, «не нашёл» — return после цикла.
Частая ошибка: else: return True внутри цикла. Функция ответит на первом же витке — и 9 станет «простым».

Функция из функций

def nod(a, b):
    """НОД — алгоритм Евклида."""
    while b > 0:
        t = a % b
        a = b
        b = t
    return a

def nok(a, b):
    return a // nod(a, b) * b

nok зовёт nod: одна проверенная функция становится кирпичом для следующей.

Строка в тройных кавычках — документация. help(nod) покажет её, как у math.isqrt в прошлый раз.

Функция, которая отвечает True или False, — признак: if is_prime(x): читается как фраза.
