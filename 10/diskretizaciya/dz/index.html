Домашнее задание — дискретизация: длины и площади

10 класс, углублённый уровень. Читаем программы, которые считают по частям: что насчитают прямоугольники и трапеции под графиком, какой длины ломаная, сколько клеток окажется внутри фигуры; ищем данные, на которых врёт программа подсчёта площади; отвечаем на вопросы про дискретизацию. Python не нужен.

Что нужно сделать
Закрыть шесть типов задач — по одной верно решённой на каждый. Ошибся — тип не закрыт, и следующей придёт новая задача того же типа: разбор только что показан, примени его. Новых задач сколько угодно.
Отметка
Четыре закрытых типа — «3», пять — «4», шесть — «5», сколько бы ошибок ни было по дороге: исправленная задача тип не закрывает, но вместо неё приходит новая — добирать можно до пятёрки. Меньше четырёх типов — кода не будет: сдавать нечего.
Главный приём — таблица шагов на бумаге
Выпиши столбиком, что происходит на каждом шаге цикла: x, f(x) и площадь полоски — для прямоугольников и трапеций, Δx, Δy и длину звена — для ломаной, какие y подходят при каждом x — для клеток. Шаг h = (b - a) / n — деление /, оно всегда даёт вещественное число, и Python печатает его с точкой: 2.0, а не 2; дробная часть — через точку, не через запятую. Ответ — всё напечатанное через пробел. Считать в уме и на бумаге: на проверочной Python тоже не будет.
Как сдать
В конце появится кнопка «Сдать работу»: впишешь код ученика, кнопка сама откроет форму с уже вписанным кодом. Переписывать код руками не надо — именно на этом чаще всего и ошибаются.
