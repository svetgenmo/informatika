Обработка данных в файлах

Программа берёт числа не с клавиатуры, а из файла.
10 класс, углублённый уровень — занятие восьмое.

Урок 16 плана: текстовые и двоичные файлы, файловая переменная, чтение из файла, запись в файл. На ЕГЭ так устроено задание 17: файл на десять тысяч чисел, руками не посчитать — только программой.

Текстовый файл

Символы и переводы строк. Открывается Блокнотом: 17.txt, .py, .csv.

Двоичный файл

Байты в своём формате: картинка, архив, программа. Блокнот покажет мусор — читают их иначе.

Открыть файл и пройти по строкам

f = open("17.txt")
k = 0
for line in f:
    x = int(line)
    if x % 3 == 0:
        k = k + 1
print(k)

f — файловая переменная (указатель): не содержимое файла, а «закладка», которая помнит, докуда прочитано.

line — строка, то есть текст: "-17\n". Считать с ней нельзя — сначала int(line), перевод строки int() отбросит сам.

Имя без пути — файл ищется в папке программы. Положите 17.txt рядом с .py.

readline() — одна строка

f = open("data.txt")
n = int(f.readline())
s = 0
for i in range(n):
    x = int(f.readline())
    s = s + x
print(s)

Напечатает 35. Закладка двигается сама: каждый readline() берёт следующую строку.

А если вместо range(n) написать for line in f? Цикл пойдёт со второй строки до конца файла — и прибавит 100.

Ловушка: последняя цифра отрицательного

В файлах ЕГЭ числа от −10000 до 10000. Какие оканчиваются на 7?

x % 10 == 7

−17 % 10 == 3 — пропустит.
−13 % 10 == 7 — засчитает.

abs(x) % 10 == 7

Последняя цифра — у модуля числа. Для −17 это 7, для −13 — 3.

Почему: в Python остаток от деления на 10 всегда от 0 до 9. −17 = 10 · (−2) + 3.

А x % 3 == 0 и x % 5 == 0 на отрицательных работают верно: делимость от знака не зависит.

Ловушка: старт наибольшего

Так — неверно

m = 0
for line in f:
    x = int(line)
    if abs(x) % 10 == 7:
        if x > m:
            m = x

Если все числа на 7 отрицательные — напечатает 0, которого в файле нет.

Так — верно

m = -10001
for line in f:
    x = int(line)
    if abs(x) % 10 == 7:
        if x > m:
            m = x

Старт меньше любого возможного числа: первое же подходящее его заменит.

Та же фраза, что в прошлой паре: «m — наибольшее из прочитанных подходящих» обязана быть верной до цикла.

Пары соседних: prev и x

f = open("17.txt")
prev = int(f.readline())
c = 0
for line in f:
    x = int(line)
    if (prev + x) % 3 == 0:
        c = c + 1
    prev = x
print(c)
файлпара (prev; x)сумма
4—
5(4; 5)9 ✓
7(5; 7)12 ✓
1(7; 1)8

Первое число читаем до цикла, в конце витка prev = x. Чисел четыре — пар три.

prev = 0 добавит пару (0; 4). А если первое число кратно 3 — эта лишняя пара засчитается.

Два прохода: когда условие зависит от всего файла

«Пары, где сумма больше наибольшего числа файла на 7». Пока файл не прочитан до конца, этого числа не знает никто.

f = open("17.txt")
M = -10001
for line in f:                 # первый проход: ищем M
    ...
f.close()
f = open("17.txt")             # закладка снова в начале
prev = int(f.readline())
for line in f:                 # второй проход: пары
    ...

Без повторного open второй цикл не сделает ни одного витка: закладка стоит в конце файла. Списков мы не знаем — и не нужно.

best — лучшая до сих пор.

Сравнивать best только при обрыве серии — ошибка: серия в самом конце файла ничем не обрывается.
Сравнение — на каждом шаге, строгое >: при равной длине остаётся первая серия.

Запись в файл

f = open("data.txt")
g = open("out.txt", "w")
for line in f:
    x = int(line)
    if x > 0:
        print(x, file=g)
g.close()
РежимЧто делает
"r" (по умолчанию)чтение
"w"запись: старое содержимое стирается
"a"дописать в конец

print(..., file=g) пишет строку не на экран, а в файл. g.close() — чтобы всё записанное точно оказалось на диске.

Как работаем

  1. Открываем практикум из общей папки — сначала тренажёр: шесть задач на чтение программ с файлом, оценки за него нет.
  2. Под каждым заданием — кнопка «Скачать учебный файл». Кладём его рядом с программой, там же написано, что должно выйти.
  3. Пишем три программы в IDLE, сохраняем как zadanie1.py, zadanie2.py, zadanie3.py.
  4. Проверка.bat → «Найти мои файлы» → «Проверить всё».
Файл открываем по имени, без пути: open("1.txt"). Ошиблась программа — оболочка положит в папку файл proverka-1.txt, на котором это случилось.

Отметка: три задания — «5», два — «4», одно — «3». Попыток сколько угодно.
