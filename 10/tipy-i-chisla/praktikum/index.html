Переменная — это ярлык

В C++, Java и C# тип объявляют заранее: int x = 5; — и строку в x уже не положить. Это статическая типизация: ошибки типов ловятся до запуска. В Python тип принадлежит значению, а переменная — просто имя, привязанное к нему: после x = 5 можно написать x = "пять". Это динамическая типизация. Узнать тип значения — type(x).

Целые: деление с остатком

print(17 // 5, 17 % 5)      # 3 2
print(-17 // 5, -17 % 5)    # -4 3  — вниз, а остаток от 0 до 4
print(divmod(17, 5))        # (3, 2) — сразу оба
print(2 ** 100)             # 1267650600228229401496703205376 — размер не ограничен

Тождество, которое держит всё: a == (a // b) * b + a % b. Отсюда цифры числа (n % 10 и n // 10) и проверка делимости: n % d == 0.

Вещественные: точность и округление

print(0.1 + 0.2)            # 0.30000000000000004
print(0.7 + 0.1 >= 0.8)     # False!  0.7999999999999999
print(round(2.5), round(3.5))   # 2 4  — половина к чётному
print(int(3.9), int(-3.9))  # 3 -3  — отбросить, а не округлить
print(f"{2.5:.2f}")         # 2.50  — вид, а не значение

Дроби вроде 0.1 в двоичной системе бесконечны, как 1/3 в десятичной, и хранятся с округлением. Поэтому вещественные числа сравнивают через допуск: abs(a - b) < 0.000001, либо округляют до нужного знака: round(a, 2) == round(b, 2).

Случайные числа

Подключаем модуль так, чтобы звать функции по имени, без приставки: from random import *. После этого своим переменным нельзя давать имена функций — переменная seed затрёт функцию seed().

ВызовЧто даёт
randint(a, b)целое от a до b, оба конца включаются
randrange(a, b)целое от a до b−1, как range
random()вещественное от 0 включительно до 1 не включая
randrange(a, b, s)от a до b−1 с шагом s: 0, 5, 10, …
seed(число)задаёт начало: дальше числа при каждом запуске одни и те же

Случайности внутри компьютера нет: следующее число вычисляется из предыдущего по формуле, поэтому числа псевдослучайные. Начальное значение обычно берётся от часов, и запуски различаются. seed закрепляет начало — так повторяют тест, розыгрыш или ошибку.

Задание 1 Делители

Заказ из n одинаковых коробок надо выложить прямоугольником — рядами по одинаковому числу коробок. Сколько коробок может быть в ряду? Столько, на сколько n делится нацело. Программа читает натуральное число n (не больше 10 000) и печатает все его делители по возрастанию через пробел, а второй строкой — сколько их.

Вход

12

Вывод

1 2 3 4 6 12
Делителей: 6

Проверяется: % в цикле, границы range. Это первый шаг к заданию 25 ЕГЭ — там перебирают делители точно так же.

Если застрял

Перебери все d от 1 до n и проверь каждое: n % d == 0. Печатать в одну строку помогает print(d, end=" "), а после цикла — пустой print(), чтобы перейти на новую строку.

Проверь на бумаге края: у числа 1 один делитель, у 36 — девять (шестёрка считается один раз), у простого 97 — два. Если у тебя у 12 вышло пять делителей — посмотри, входит ли правая граница в range.

Задание 2 Зарплата курьера

Курьеру платят за километры. Программа читает ставку в рублях за километр, дневной план в километрах, число поездок n, а потом n расстояний в километрах — все с одним знаком после точки. Печатает общий пробег и заработок с двумя знаками после точки, а третьей строкой — выполнен ли план: пробег не меньше плана.

Вход

35.5
10.0
3
4.2
3.5
2.3

Вывод

Пробег: 10.00 км
Заработок: 355.00 руб.
План выполнен

Проверяется: float(input()), накопление суммы, формат :.2f — и сравнение вещественных.

Если застрял

Сумму копи в цикле: total = total + float(input()). Два знака после точки даёт только формат: print(f"Пробег: {total:.2f} км"); round(total, 2) напечатает 10.0, а не 10.00.

Ловушка, ради которой это задание. Поездки 0.7 и 0.1, план 0.8. По арифметике план выполнен ровно. Но 0.7 + 0.1 в компьютере — это 0.7999999999999999, и total >= plan скажет «не выполнен». Оболочка подаст именно такие данные. Сравнивай с точностью до сотых: round(total, 2) >= plan, — либо с допуском: total + 0.000001 >= plan.

Задание 3 Кубик

Программа читает два целых числа: начальное число start и количество бросков n. Перед бросками вызывается seed(start) — чтобы серию можно было повторить и проверить. Дальше кубик бросается n раз. Печатай три строки: сами броски через пробел, их сумму и сколько раз выпала шестёрка.

Вход

7
5

Вывод

Броски: 3 6 1 6 2   # числа у всех свои
Сумма: 18
Шестёрок: 2

Проверяется: seed, randint, границы диапазона, накопление суммы и счётчик. Правильного ответа у задания нет — оболочка проверяет, что бросков ровно n и все от 1 до 6, что сумма и число шестёрок сходятся с напечатанными бросками, что при одном начальном числе серия повторяется, а при другом — нет.

Если застрял

Бросок — это randint(1, 6). Печатать в одну строку помогает print(x, end=" "), а после цикла пустой print() — ровно как в первом задании с делителями. Сумму и счётчик шестёрок копи в переменных прямо в цикле:

from random import *

start = int(input())
n = int(input())
seed(start)
total = 0
sixes = 0
print("Броски:", end=" ")
for i in range(n):
    x = randint(1, 6)
    print(x, end=" ")
    total = total + x
    if x == 6:
        sixes = sixes + 1
print()
print("Сумма:", total)
print("Шестёрок:", sixes)

Переменную с начальным числом не называй seed: после from random import * это имя функции, и seed = int(input()) её затрёт — seed(seed) упадёт с ошибкой.

Ловушка, ради которой это задание. Следи за границей: randint(1, 6) шестёрку включает, а randrange(1, 6) — нет, она даёт только от 1 до 5. Оболочка подаст серию из сотни с лишним бросков: в ней обязаны встретиться все шесть граней, и кубик без шестёрки сразу виден.

Подсказка: типы данных, числа и случайность

В C++, Java, C# тип у переменной и объявляется заранее (статическая типизация). В Python тип у значения, переменная — ярлык: после x = 5 можно x = "пять" (динамическая). Узнать тип: type(x). Целые в Python не ограничены размером; в C++ int — 32 бита, около 2 миллиардов.

Целые

a == (a // b) * b + a % b — всегда, и для отрицательных. divmod(17, 5) даёт (3, 2). Цифры числа: n % 10 — последняя, n // 10 — отрезать её. Делимость: n % d == 0 — так перебирают делители (задание 25 ЕГЭ).

Вещественные

0.1 в двоичной системе — бесконечная дробь, хранится с округлением: 0.1 + 0.2 = 0.30000000000000004, 0.7 + 0.1 < 0.8. Сравнивать через допуск abs(a − b) < 1e-6 или округлять: round(a, 2). «/» всегда даёт float (6 / 3 = 2.0), «//» с вещественным — тоже float (7 // 2.0 = 3.0). round(x) → int, половина к чётному: round(2.5) = 2, round(3.5) = 4. int(x) отбрасывает дробную часть: int(-3.9) = -3. Формат f"{x:.2f}" меняет вид, а не число: 2.5 → "2.50".

Строки и логика

input() всегда строка: "5" * 3 = "555", "9" > "10" (сравнение посимвольно). int("5.0") — ошибка, сначала float(). True хранится как 1, False как 0; bool от нуля и пустой строки — False, от всего остального — True. 3 == 3.0 → True, "3" == 3 → False. Цепочка 1 < x < 10 — это 1 < x and x < 10.

Случайные числа

Подключение: from random import * — функции зовутся по имени. Своим переменным имена функций не давать: seed = … затрёт seed().

вызовчто даёт

randrange(a, b)от a до b−1, как range

randrange(a, b, s)от a до b−1 с шагом s

Числа псевдослучайные: следующее считается из предыдущего по формуле. Без seed начало берётся от часов. seed нужен, чтобы повторить тест, розыгрыш или ошибку.
