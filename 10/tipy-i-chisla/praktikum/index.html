Переменная — это ярлык

В C++, Java и C# тип объявляют заранее: int x = 5; — и строку в x уже не положить. Это статическая типизация: ошибки типов ловятся до запуска. В Python тип принадлежит значению, а переменная — просто имя, привязанное к нему: после x = 5 можно написать x = "пять". Это динамическая типизация. Узнать тип значения — type(x).

Целые: деление с остатком

Тождество, которое держит всё: a == (a // b) * b + a % b. Отсюда цифры числа (n % 10 и n // 10) и проверка делимости: n % d == 0.

Вещественные: точность и округление

Дроби вроде 0.1 в двоичной системе бесконечны, как 1/3 в десятичной, и хранятся с округлением. Поэтому вещественные числа сравнивают через допуск: abs(a - b) < 0.000001, либо округляют до нужного знака: round(a, 2) == round(b, 2).

Случайные числа

Подключаем модуль так, чтобы звать функции по имени, без приставки: from random import *. После этого своим переменным нельзя давать имена функций — переменная seed затрёт функцию seed().

ВызовЧто даёт
randint(a, b)целое от a до b, оба конца включаются
randrange(a, b)целое от a до b−1, как range
random()вещественное от 0 включительно до 1 не включая
randrange(a, b, s)от a до b−1 с шагом s: 0, 5, 10, …
seed(число)задаёт начало: дальше числа при каждом запуске одни и те же

Случайности внутри компьютера нет: следующее число вычисляется из предыдущего по формуле, поэтому числа псевдослучайные. Начальное значение обычно берётся от часов, и запуски различаются. seed закрепляет начало — так повторяют тест, розыгрыш или ошибку.

В C++, Java, C# тип у переменной и объявляется заранее (статическая типизация). В Python тип у значения, переменная — ярлык: после x = 5 можно x = "пять" (динамическая). Узнать тип: type(x). Целые в Python не ограничены размером; в C++ int — 32 бита, около 2 миллиардов.

Целые

a == (a // b) * b + a % b — всегда, и для отрицательных. divmod(17, 5) даёт (3, 2). Цифры числа: n % 10 — последняя, n // 10 — отрезать её. Делимость: n % d == 0 — так перебирают делители (задание 25 ЕГЭ).

Вещественные

0.1 в двоичной системе — бесконечная дробь, хранится с округлением: 0.1 + 0.2 = 0.30000000000000004, 0.7 + 0.1 < 0.8. Сравнивать через допуск abs(a − b) < 1e-6 или округлять: round(a, 2). «/» всегда даёт float (6 / 3 = 2.0), «//» с вещественным — тоже float (7 // 2.0 = 3.0). round(x) → int, половина к чётному: round(2.5) = 2, round(3.5) = 4. int(x) отбрасывает дробную часть: int(-3.9) = -3. Формат f"{x:.2f}" меняет вид, а не число: 2.5 → "2.50".

Строки и логика

input() всегда строка: "5" * 3 = "555", "9" > "10" (сравнение посимвольно). int("5.0") — ошибка, сначала float(). True хранится как 1, False как 0; bool от нуля и пустой строки — False, от всего остального — True. 3 == 3.0 → True, "3" == 3 → False. Цепочка 1 < x < 10 — это 1 < x and x < 10.
