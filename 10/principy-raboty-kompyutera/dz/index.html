Девять типов заданий: четыре — про то, как устроен и работает компьютер, пять — про выбор конфигурации под задачу.

Как устроено
Задачи идут по одной, ответ выбирается кликом — не набирается с клавиатуры. Тип считается закрытым, когда ответишь на него верно два раза подряд. Ошибся — счёт по этому типу начинается заново, зато сразу увидишь разбор.

Как сдать
В конце появится кнопка «Сдать работу»: впишешь фамилию и класс, кнопка сама откроет форму с уже вписанным кодом. Останется нажать «Отправить». Переписывать код руками не надо.

Пять принципов фон Неймана — коротко

Хранимая программа. Команды программы и данные, с которыми она работает, лежат в одной и той же памяти. Программа для процессора — тоже данные.

Адресуемость памяти. У каждой ячейки памяти есть номер — адрес. Процессор обращается по адресу, а не ищет по содержимому.

Последовательное выполнение. Пока не встретится команда перехода, команды выполняются одна за другой, строго по порядку.

Энергозависимость. Оперативная память живёт, пока есть питание. Долговременная память (диск, SSD, флешка) хранит данные и без питания.

Выбор конфигурации — не «чем мощнее, тем лучше»

У задачи есть минимум: процессор, память, накопитель, видеокарта нужного уровня. Сборка ниже минимума задачу не потянет. Сборка выше минимума задачу потянет, но часть денег уйдёт туда, где эффекта не будет. Правильный выбор — сборка, которая отвечает минимуму по всем параметрам и не переплачивает ни за один.
