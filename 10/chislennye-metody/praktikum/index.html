Часть 2. Как решают уравнение численно

Где корень: смена знака

Если функция непрерывна, а на концах отрезка у неё разные знаки, на этом отрезке есть корень: от минуса к плюсу нельзя перейти, не пройдя через ноль. Проверка одной строкой — произведение меньше нуля: f(a) * f(b) < 0. Одинаковые знаки ничего не гарантируют: корней может не быть, а может быть два.

Отделение корней — перебор с шагом

Программа печатает отрезки -3 -2, 0 1, 2 3 — на каждом по корню. Последний x в range(a, b) — это b − 1, поэтому отрезок [b − 1; b] тоже проверен.

Уточнение — половинное деление

Каждый шаг вдвое укорачивает отрезок, где лежит корень. От длины 1 до 0.001 — всего 10 шагов: 2¹⁰ = 1024. Перебор с шагом 0.001 потратил бы тысячу вычислений. Знак <=, а не <: если середина попала точно в корень, f(c) = 0 — корень остаётся на отрезке.

Вещественные числа

Деление / всегда даёт вещественное число: 10 / 5 — это 2.0. Вещественные хранятся приближённо (0.1 + 0.2 — это 0.30000000000000004), поэтому их не сравнивают через ==, а цикл пишут через «длина больше точности». Ровно три знака после точки печатает f"{x:.3f}"; round(x, 3) для этого не годится — у него round(2.0, 3) это 2.0.

Подсказка: численные методы

Численный метод

Корень уравнения f(x) = 0 ищут приближённо: считают f в разных точках и сужают место, где лежит корень, до нужной точности.

Смена знака

Непрерывная f разного знака на концах отрезка — на нём есть корень. Проверка: f(a) * f(b) < 0. Одинаковые знаки ничего не гарантируют.

Отделение корней

Перебор с шагом: for x in range(a, b), условие f(x) * f(x + 1) < 0 — на отрезке [x; x + 1] корень. Последний x — это b − 1.

Половинное деление

Пока b − a больше точности: c = (a + b) / 2; если f(a) * f(c) <= 0 — b = c, иначе a = c. Ответ — середина последнего отрезка, ошибка не больше половины точности.

Сколько шагов

Каждый шаг делит отрезок пополам: из длины 1 до 0.001 — 10 шагов, потому что 2¹⁰ = 1024. Перебор с шагом 0.001 — тысяча вычислений.

Вещественные числа

/ всегда даёт вещественное: 10 / 5 это 2.0. Вещественные не сравнивают через ==. Три знака после точки — f"{x:.3f}".
