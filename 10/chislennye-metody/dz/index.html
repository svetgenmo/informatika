Домашнее задание — численные методы

10 класс, углублённый уровень. Читаем программы, которые решают уравнения приближённо: какие отрезки найдёт отделение корней, что напечатает подбор с шагом, где окажется отрезок после нескольких шагов половинного деления и сколько шагов нужно до заданной точности; ищем данные, на которых врёт программа подсчёта корней; отвечаем на вопросы про численные методы. Python не нужен.

Что нужно сделать
Закрыть шесть типов задач — по одной верно решённой на каждый. Ошибся — тип не закрыт, и следующей придёт новая задача того же типа: разбор только что показан, примени его. Новых задач сколько угодно.
Отметка
Четыре закрытых типа — «3», пять — «4», шесть — «5», сколько бы ошибок ни было по дороге: исправленная задача тип не закрывает, но вместо неё приходит новая — добирать можно до пятёрки. Меньше четырёх типов — кода не будет: сдавать нечего.
Главный приём — таблица шагов на бумаге
Выпиши столбиком, что происходит на каждом шаге цикла: x и f(x) — для отделения корней, a, b, c и знак f(c) — для половинного деления, длину отрезка — для числа шагов. Корень там, где f меняет знак: произведение соседних значений меньше нуля. Деление / всегда даёт вещественное число, и Python печатает его с точкой: 2.0, а не 2; дробная часть — через точку, не через запятую. Ответ — всё напечатанное через пробел. Считать в уме и на бумаге: на проверочной Python тоже не будет.
Как сдать
В конце появится кнопка «Сдать работу»: впишешь код ученика, кнопка сама откроет форму с уже вписанным кодом. Переписывать код руками не надо — именно на этом чаще всего и ошибаются.
