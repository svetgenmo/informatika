Модульный принцип

Тринадцатое занятие углублённого курса: модуль как файл с функциями, import и from, защита if __name__ == "__main__", пространство имён модуля, импорт один раз, модуль подключает модуль; два модуля из своих функций и три программы, которые их подключают, — уроки 25–26 плана · 10 класс

Разбор темыМодульный принцип: одна функция — три копии, и почему так плохо; модуль — это файл, import выполняет его целиком; четыре способа подключить (import, from, as, звёздочка); проверки модуля под if __name__ == "__main__"; у модуля свои имена; модуль выполняется один раз; модуль подключает модуль; что такое модульный принцип и почему свой файл не называют random.py.
