Домашнее задание — модульный принцип

10 класс, углублённый уровень. Читаем программы из нескольких файлов: что напечатает импорт модуля, какой файл запущен и что тогда делает if __name__ == "__main__", чья переменная окажется в функции, в какой строке программа упадёт; ищем данные, на которых врёт модуль; отвечаем на вопросы про модули. Python не нужен.

Что нужно сделать
Закрыть шесть типов задач — по одной верно решённой на каждый. Ошибся — тип не закрыт, и следующей придёт новая задача того же типа: разбор только что показан, примени его. Новых задач сколько угодно.
Отметка
Четыре закрытых типа — «3», пять — «4», шесть — «5», сколько бы ошибок ни было по дороге: исправленная задача тип не закрывает, но вместо неё приходит новая — добирать можно до пятёрки. Меньше четырёх типов — кода не будет: сдавать нечего.
Главный приём — идти по строкам запускаемого файла
Дошёл до import — выполни файл модуля сверху вниз, если он ещё не загружен: def только запоминает функцию, а print печатает сразу. Второй import того же модуля ничего не выполняет. После import calc функции зовут через точку, после from calc import f — без неё. Ответ — всё напечатанное через пробел или номер строки, о котором спрашивают. Считать в уме и на бумаге: на проверочной Python тоже не будет.
Как сдать
В конце появится кнопка «Сдать работу»: впишешь фамилию и класс, кнопка сама откроет форму с уже вписанным кодом. Переписывать код руками не надо — именно на этом чаще всего и ошибаются.
