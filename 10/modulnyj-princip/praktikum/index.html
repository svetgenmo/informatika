Модульный принцип — практикум

10 класс, углублённый уровень. Занятие тринадцатое. Модуль — файл с функциями, который подключают в любую программу: import и from, защита if __name__ == "__main__", свои имена у каждого модуля, импорт один раз, модуль внутри модуля.

План на пару. Сначала тренажёр: шесть коротких задач о том, как работают модули, — что напечатает импорт, какой файл запущен, чьё имя, импорт один раз, где программа упадёт, цепочка модулей. Потом два модуля из своих функций прошлых пар и три программы, которые их подключают. Проверяет оболочка Проверка.bat из общей папки: она запускает программу на девяти наборах данных, смотрит, что модуль при импорте молчит и каждая его функция возвращает верное, а программа берёт функции из модуля, а не пишет их заново. Интернет не нужен.

Часть 1. Тренажёр: как работают модули

Шесть типов задач, по одной на каждый. В каждой задаче два-три файла: модуль (или два) и main.py, который их подключает. Считать в уме или на бумаге: иди по строкам запускаемого файла, а на строке import — выполни файл модуля сверху вниз, если он ещё не загружен. Ответ — всё напечатанное через пробел, или номер строки, о котором спрашивают. Ошибся — ниже появится разбор рисунком: какая строка какого файла что сделала и что напечатала, — и кнопка «Новые числа»: реши такую же ещё раз.

Часть 2. Как устроены модули

Модуль — это файл

Имя модуля — имя файла без .py. Python ищет его сначала в папке запущенной программы, потом в своей библиотеке. При import файл модуля выполняется целиком: def запоминает функцию, а print, если он стоит в модуле просто так, срабатывает сразу.

Четыре способа подключить

ПодключениеКак зватьЧто появилось в программе
import mytoolsmytools.digsum(n)имя mytools
from mytools import digsumdigsum(n)имя digsum, а mytools — нет

Имя модуля пишется без .py: import mytools.py падает с ModuleNotFoundError.

Проверки модуля — под защитой

__name__ у запущенного файла — "__main__", у подключённого — имя модуля. Поэтому блок под if работает, когда модуль проверяют сам по себе, и молчит, когда его импортирует программа.

У модуля свои имена

Функция ищет переменные в том модуле, где написана. k = 100 в программе не меняет k модуля — это другая переменная. Изменить переменную модуля — через точку: calc.k = 100. Своя def f в программе заменяет импортированную f — поэтому функций с именами из модуля у себя не заводят.

Модуль выполняется один раз

Первый import выполняет файл, следующие берут уже загруженный модуль — сколько бы раз и откуда его ни подключали. Модуль может подключать модуль: если в b.py стоит from a import f, у модуля b есть имя f.

Часть 3. Два модуля и три программы

  • Все пять файлов — mytools.py, datetools.py, zadanie1.py … zadanie3.py — в одну новую папку. Программа находит модуль только рядом с собой.
  • Функции — в модулях, с теми именами, что в задании. Возьми их из своих решений пар 10 и 11: так и работает модульный принцип. Оболочка зовёт каждую функцию модуля напрямую и смотрит, что она вернула.
  • Модуль при импорте молчит. Свои проверки модуля — под if __name__ == "__main__":. Модуль, который печатает при импорте или ждёт input(), задание не сдаёт.
  • Программа берёт функции из модуля. def is_prime в самой программе — задание не принято, даже если вывод верный.
  • Никаких приглашений в input(). Пиши input(), а не input("Введите год: ") — вывод читает машина.
  • Выводи ровно то, что просят: те же слова, тот же порядок строк.

Подсказка: модули

Модуль — это файл

Модуль — файл .py с функциями. Имя модуля — имя файла без .py: import mytools. Файл лежит в папке программы. При import модуль выполняется целиком, сверху вниз.

Как подключить

import mytools — функции через точку: mytools.digsum(n). from mytools import digsum — просто digsum(n), но имени mytools нет. import mytools as mt — mt.digsum(n).

Защита модуля

if __name__ == "__main__": — блок работает, только когда запускают сам модуль. У запущенного файла __name__ равно "__main__", у подключённого — имя модуля.

Свои имена

У каждого модуля своё пространство имён: функция видит переменные своего модуля. k = 100 в программе не меняет k модуля; calc.k = 100 — меняет.

Один раз

Модуль выполняется при первом import, дальше берётся уже загруженный. Модуль может подключать модуль: что он импортировал, то у него и есть.

Модульный принцип

Программа делится на части с ясным назначением; каждую пишут и проверяют отдельно, а подключают, а не копируют. Своё не называют именами библиотеки: random.py рядом заслонит настоящий random.
