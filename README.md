# Информатика — материалы к урокам

Страницы для учеников: открываются в браузере, ничего не нужно
скачивать и устанавливать, вход никуда не требуется.

**Оглавление всех тем: https://svetgenmo.github.io/informatika/**

## Устройство адресов

```
/                                       все темы
/<класс>/<тема>/                        материалы одной темы
/<класс>/<тема>/dz/                     домашнее задание
/<класс>/<тема>/trenazher/              тренажёр без сдачи
/<класс>/<тема>/prezentaciya/           разбор темы
```

Сейчас здесь одна тема — [системы счисления, 8 класс](https://svetgenmo.github.io/informatika/8/sistemy-schisleniya/).
Дальше добавятся остальные; адреса уже разведены по классам и темам,
поэтому старые ссылки ломаться не будут.

## Что здесь есть и чего нет

Страницы **никого не опознают и ничего не хранят**: числа в задачах
генерируются в браузере при каждом открытии, ответы никуда не
отправляются, у страниц нет ни базы, ни сервера.

Здесь **нет** списков учеников, оценок, ведомостей и ключей с ответами —
и не будет. Всё это живёт на компьютере учителя и в интернет не выходит.

## Как это обновляется

Репозиторий — витрина, а не мастерская. Исходники лежат у учителя;
страницы и оглавления собираются оттуда одной командой и выкладываются
сюда. Править файлы прямо здесь не нужно: правки затрёт следующая сборка.
