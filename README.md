# Информатика — материалы к урокам

Страницы для учеников: открываются в браузере, ничего не нужно
скачивать и устанавливать.

- **[Домашнее задание: системы счисления](https://svetgenmo.github.io/informatika/)**
  — шесть переводов, разбор при ошибке, код работы для сдачи.
- **[Тренажёр: шесть переводов](https://svetgenmo.github.io/informatika/trenazher/)**
  — то же самое без сдачи, для отработки.

## Что здесь есть и чего нет

Страницы **никого не опознают и ничего не хранят**: числа в задачах
генерируются в браузере при каждом открытии, ответы никуда не
отправляются, у страницы нет ни базы, ни сервера.

Здесь **нет** списков учеников, оценок, ведомостей и ключей с ответами —
и не будет. Всё это живёт на компьютере учителя и в интернет не выходит.

## Как это обновляется

Репозиторий — витрина, а не мастерская. Исходники лежат у учителя;
страницы собираются оттуда одной командой и выкладываются сюда.
Править файлы прямо здесь не нужно: правки затрёт следующая сборка.
