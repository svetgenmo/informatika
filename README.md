## Устройство адресов

```
/                                  все классы
/<класс>/                          все темы класса
/<класс>/<тема>/                   материалы одной темы
/<класс>/<тема>/dz/                домашнее задание
/<класс>/<тема>/trenazher/         тренажёр без сдачи
/<класс>/<тема>/prezentaciya/      разбор темы
```

Адреса разведены по классам и темам, поэтому уже выданные
ссылки не ломаются, когда добавляются новые темы.

## Что здесь есть и чего нет

Страницы **никого не опознают и ничего не хранят**: числа в
задачах генерируются в браузере при каждом открытии, ответы
никуда не отправляются, у страниц нет ни базы, ни сервера.

Здесь **нет** списков учеников, оценок, ведомостей и ключей с
ответами — и не будет. Всё это живёт на компьютере учителя и в
интернет не выходит.

## Как это сделано

Материалы подготовлены с использованием технологий
искусственного интеллекта.

## Как это обновляется

Репозиторий — витрина, а не мастерская. Исходники лежат у
учителя; страницы, оглавления и этот файл собираются оттуда
одной командой и выкладываются сюда. Править файлы прямо
здесь не нужно: правки затрёт следующая сборка.
