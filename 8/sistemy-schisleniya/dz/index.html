Подсказка: как переводить

Прочитать число — развёрнутая форма

Каждую цифру умножаем на основание в степени её позиции. Позиции справа налево, с нуля.

1 1 0 1₂ = 1·2³ + 1·2² + 0·2¹ + 1·2⁰ = 8 + 4 + 0 + 1 = 13
3 5 7₈  = 3·8² + 5·8¹ + 7·8⁰  = 192 + 40 + 7 = 239
A 4₁₆   = 10·16¹ + 4·16⁰      = 160 + 4      = 164

Записать число — деление с остатком

Делим на основание, пока не выйдет 0. Остатки читаем снизу вверх.

94 : 2 = 47  ост. 0   ↑
47 : 2 = 23  ост. 1   │
23 : 2 = 11  ост. 1   │  читаем
11 : 2 =  5  ост. 1   │  в эту
 5 : 2 =  2  ост. 1   │  сторону
 2 : 2 =  1  ост. 0   │
 1 : 2 =  0  ост. 1   │   94 = 1011110₂
