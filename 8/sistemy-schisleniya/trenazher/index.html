Подсказка: как переводить

Из любой системы в десятичную — развёрнутая форма

Каждую цифру умножаем на основание в степени её позиции. Позиции считаем справа налево, начиная с нуля.

1 1 0 1₂ = 1·2³ + 1·2² + 0·2¹ + 1·2⁰ = 8 + 4 + 0 + 1 = 13
3 5 7₈  = 3·8² + 5·8¹ + 7·8⁰  = 192 + 40 + 7    = 239
A 4₁₆   = 10·16¹ + 4·16⁰      = 160 + 4         = 164

Из десятичной в любую — деление с остатком

Делим на основание, пока не получится 0. Остатки читаем снизу вверх.

94 : 2 = 47  ост. 0   ↑
47 : 2 = 23  ост. 1   │
23 : 2 = 11  ост. 1   │  читаем
11 : 2 =  5  ост. 1   │  в эту
 5 : 2 =  2  ост. 1   │  сторону
 2 : 2 =  1  ост. 0   │
 1 : 2 =  0  ост. 1   │      94 = 1011110₂
350 : 16 = 21  ост. 14 -> E   ↑
 21 : 16 =  1  ост.  5 -> 5   │
  1 : 16 =  0  ост.  1 -> 1   │   350 = 15E₁₆

Помни

— В системе с основанием q используются цифры от 0 до q−1. В двоичной нет цифры 2, в восьмеричной нет 8 и 9.

— Основание в ответе писать не нужно: просто 1011110.
