Подсказка: сети, адреса, домены

Из чего состоит сеть

Компьютеры соединяет сетевая карта — проводом или по Wi-Fi. Внутри дома или кабинета всё сводится в коммутатор, а наружу, в другие сети, ведёт маршрутизатор (роутер). Он же — шлюз: первый узел, через который уходит всё, что адресовано не соседу по кабинету. Дальше идут сети провайдера, и так до сервера — интернет и есть сеть сетей.

Протокол — это договор

Протокол — набор правил, о которых договорились обе стороны. IP отвечает за адреса и доставку пакета; TCP — за то, чтобы пакеты не потерялись и собрались в правильном порядке; HTTP и HTTPS — за разговор браузера с веб-сервером (у HTTPS всё зашифровано); DNS — за перевод имён в адреса.

IP-адрес

Адрес IPv4 — четыре числа от 0 до 255 через точку: 84.201.157.12. Каждое число — один байт, весь адрес — 4 байта, 32 бита. Поэтому всего адресов 232 ≈ 4,3 млрд — и на всех уже не хватает.

Три диапазона отданы под локальные сети: 10.*.*.*, 172.16.*.*–172.31.*.* и 192.168.*.*. Они повторяются в миллионах домашних сетей, в интернете не маршрутизируются, и снаружи по ним не достучаться. Весь кабинет выходит наружу под одним публичным адресом роутера — это называется NAT.

Доменное имя и DNS

Числа человек не запоминает, поэтому у серверов есть имена. Имя читают справа налево: ru — домен верхнего уровня (зона), school15.edu.ru — домен второго уровня внутри зоны edu.ru, www. — уже конкретный компьютер внутри домена.

DNS — распределённая служба, которая переводит имя в IP-адрес. Своей копии всей таблицы нет ни у кого: сервер, который не знает ответа, спрашивает вышестоящий.

Как отличить подделку

Настоящее имя сайта — последние две части имени сервера, до первой одиночной косой черты. В адресе sberbank.ru.secure-login.tk/vhod вы не на sberbank.ru, а на secure-login.tk: всё, что левее, придумал владелец чужого домена.

Скорость: биты и байты

Скорость канала считают в мегабитах в секунду, а файлы — в мегабайтах. Разница ровно в 8 раз, и на ней ошибаются чаще всего. Время = объём в битах ÷ скорость: файл 900 МБ по каналу 50 Мбит/с идёт 900 · 8 ÷ 50 = 144 секунды.

Что делает браузер, когда вы ввели адрес

Спрашивает у DNS адрес по имени → получает IP → соединяется с сервером по этому IP и просит страницу → получает HTML → рисует страницу на экране. Сеть умеет доставлять пакеты только по числовому адресу, поэтому шаг с DNS всегда первый.
