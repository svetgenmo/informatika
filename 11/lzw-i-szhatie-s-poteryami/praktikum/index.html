Подсказка: LZW и сжатие с потерями

Словарное сжатие: алгоритм LZW

Идея: повторяющиеся фразы заменяются номерами из словаря. Словарь не передаётся — кодер и декодер строят его одинаково по ходу работы. В начале в словаре только отдельные символы алфавита.

  1. взять с текущего места самую длинную фразу, которая уже есть в словаре;
  2. выдать её код;
  3. занести в словарь новую фразу: эта фраза + следующий символ;
  4. продолжить с символа, на котором остановились.

Пример, словарь А = 1, Б = 2, сообщение АБАБААБ:

фразакодв словарь
А13 = АБ
Б24 = БА
АБ35 = АБА
А16 = АА
АБ3—

Выход 1 2 3 1 3: пять кодов вместо семи символов. Каждый код, кроме последнего, добавляет в словарь одну фразу.

Декодирование LZW

Читать коды по одному и выписывать фразы. После каждой фразы, начиная со второй, добавлять в словарь предыдущую фразу + первую букву текущей — получится тот же словарь, что был у кодера.

Коду из b бит хватает на 2b фраз: словарь из N фраз требует кодов длиной ⌈log2N⌉ бит.

Сжатие с потерями

Без потерь (RLE, Хаффман, LZW, ZIP, PNG, FLAC) данные восстанавливаются бит в бит. С потерями (JPEG, MP3, AAC, MPEG-4) отбрасывается то, что человек почти не замечает; назад это не вернуть. Годится для фото, звука и видео, но не для текста и программ.

  • глубина цвета: i бит на пиксель — 2i цветов; объём = ширина · высота · i. Уменьшили глубину — потеряли оттенки;
  • JPEG: яркость хранится для каждого пикселя, цветность — одна на квадрат 2 × 2; изображение делится на блоки 8 × 8; коэффициенты блока квантуются — делятся на шаг и округляются (здесь и теряется информация), затем сжимаются без потерь;
  • MP3: отбрасываются звуки, которые ухо не различает (тихие рядом с громкими). Размер задаёт битрейт: объём = битрейт · время, 128 Кбит/с = 16 Кбайт/с.
