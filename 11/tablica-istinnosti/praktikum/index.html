Что нужно сделать
Восемь задач. Первые четыре — про то, как метод устроен: их считают в голове. Остальные четыре — настоящие задания 2, они решаются программой: одно без пропусков и три с пропусками в таблице, потому что таких на ЕГЭ больше.
Баллы
Первые четыре задачи вместе стоят 1 балл — и только если верны все четыре. Каждая задача с кодом — ещё по баллу. Всего 5. Оценивание жёсткое: на «5» надо решить всё.
Ошибся — не страшно
Разбор появится сразу, а задача вернётся в конец очереди уже с новыми числами: балл можно доработать. Отдельно видно, сколько задач сделано с первой попытки.
Ответ
Буквы — подряд, латиницей, без пробелов и запятых: zxwy. Числа — целые, без пояснений. Сверка знак в знак, как на КЕГЭ.

Подсказка: как решать задание 2 программой

Логика на языке Python

в условиичитаетсяв программе
¬Aне Anot A
A ∧ BA и BA and B
A ∨ BA или BA or B
A → Bиз A следует BA <= B
A ≡ BA равносильно BA == B

Порядок действий: сначала not, потом and, потом or, и только затем <= и ==. Скобки из условия сохранять как есть.

Что делает программа

for p in permutations('xyzw'):
    if [f(**dict(zip(p, row))) for row in table] == res:
        print(*p, sep='')
  • permutations — все 24 расстановки имён по столбцам;
  • zip — склеивает имена со значениями строки;
  • dict — собирает из пар словарь;
  • ** — раскрывает словарь в именованные аргументы.

Порядок имён в def f(...) значения не имеет: аргументы попадают по именам, а не по местам.

Если в таблице есть пропуски

for a1, a2, a3 in product([0, 1], repeat=3):
    table = [(a1, 0, 1, a2), (1, 1, a3, 0), (0, 1, 1, 1)]
    if len(table) == len(set(table)):
        ...

Пустые клетки перебираются product. Проверка len(table) == len(set(table)) выбрасывает варианты с одинаковыми строками: в условии сказано, что строки различны, и это не украшение, а ограничение — без него ответ часто перестаёт быть единственным.

Как записывают ответ

Буквы подряд, без пробелов и запятых — в том порядке, в каком идут столбцы таблицы: zxwy.
