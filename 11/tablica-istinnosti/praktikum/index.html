Задание 2 ЕГЭ: таблицы истинности

11 класс, углублённый уровень. Практикум по программному методу: permutations, zip, dict и две звёздочки.

Что нужно сделать
Шесть типов задач. Тип закрывается одним верным ответом; ошибся — разбор на экране и следующая задача того же типа, пока не получится. Числа и функции новые при каждом открытии, у соседа другие.
Чем решать
Задания 2 решаются программой, а не перебором в уме: открывай IDLE, пиши решение по образцу с доски и запускай. Первые четыре типа считаются в голове — они про то, как этот код устроен.
Ответ
Буквы — подряд, латиницей, без пробелов и запятых: zxwy. Числа — целые, без пояснений. Сверка знак в знак, как на КЕГЭ.
Отметка
Сколько типов закрыто, столько и наработано: шесть — «5», пять — «4», четыре — «3». Число ошибок на отметку не влияет, но видно на экране.
Шаблон решения — если забыл, с чего начать 
from itertools import permutations, product

def f(x, y, z, w):
    return ...          # выражение F: → это <=, ≡ это ==

table = [(0, 0, 1, 1), (0, 0, 1, 0), (0, 1, 1, 1)]   # строки фрагмента
res = [1, 0, 0]                                       # столбец F

for p in permutations('xyzw'):
    if [f(**dict(zip(p, row))) for row in table] == res:
        print(*p, sep='')

С пропусками — то же самое, но таблица собирается внутри for a1, a2, a3 in product([0, 1], repeat=3), а варианты с повторяющимися строками пропускаются: if len(table) != len(set(table)): continue.
