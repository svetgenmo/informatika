Задание 2:
таблицы истинности

Второй способ решения — itertools и словарь.
11 класс, углублённый уровень.

Перебор вложенными циклами вы уже знаете. Сегодня — способ, при котором программа сама подбирает, какая переменная стоит в каком столбце, и делает это в четыре строки.

Что спрашивают

Логическая функция F задаётся выражением F = ((x → y) ∨ (z ≡ x)) ∧ (w → z). Приведён фрагмент таблицы истинности из трёх различных строк — но какому столбцу какая переменная соответствует, не указано.

????F
00111
00100
01110

Ответ — буквы в порядке столбцов, подряд и без разделителей.

Переменных четыре, значит расстановок 4! = 24. Из них подходит ровно одна — задача в том, чтобы её найти, и не глазами.

Как мы это делали: вложенные циклы

def f(x, y, z, w):
    return ((x <= y) or (z == x)) and (w <= z)

for x in range(2):
    for y in range(2):
        for z in range(2):
            for w in range(2):
                if f(x, y, z, w) == 1:
                    print(x, y, z, w)

Программа печатает все наборы, на которых F = 1, — а дальше человек глазами прикладывает их к строкам фрагмента.

Что здесь хорошо

Ничего лишнего знать не надо: четыре цикла и условие.

Что плохо

Самую трудную часть — сопоставление столбцов — делает человек. На пропусках в таблице это почти безнадёжно.

Пусть столбцы
перебирает программа

Вся идея второго способа — в одной строке:

for p in permutations('xyzw'):

permutations из модуля itertools выдаёт все 24 расстановки букв: ('x','y','z','w'), ('x','y','w','z'), … Каждая — гипотеза: «в первом столбце p[0], во втором p[1], и так далее».

Осталось научиться проверять гипотезу: подставить значения из строки таблицы в функцию — с учётом того, что имена переехали.

Задача подстановки

Пусть гипотеза p = ('z','w','x','y'), а строка таблицы row = (0, 0, 1, 1).

столбец1234
переменная pzwxy
значение row0011

Нужно вызвать f(x=1, y=1, z=0, w=0). Но p меняется на каждом шаге цикла — вручную не распишешь.

Три шага: zip склеивает, dict собирает, две звёздочки раскрывают.

Шаг 1: zip — склеить по порядку

p   = ('z', 'w', 'x', 'y')
row = ( 0 ,  0 ,  1 ,  1 )

list(zip(p, row))
[('z', 0), ('w', 0), ('x', 1), ('y', 1)]

zip берёт первый элемент оттуда и отсюда, второй оттуда и отсюда — получаются пары «имя — значение».

Порядок аргументов важен: zip(row, p) дало бы пары (0, 'z') — числа стали бы именами.

Шаг 2: dict — собрать словарь

dict(zip(p, row))
{'z': 0, 'w': 0, 'x': 1, 'y': 1}

Словарь — это набор пар «ключ: значение». Из списка пар он собирается одним вызовом.

Теперь у нас есть готовый ответ на вопрос «чему равна каждая переменная в этой строке при этой гипотезе».

Шаг 3: ** — раскрыть в аргументы

d = {'z': 0, 'w': 0, 'x': 1, 'y': 1}

f(**d)          # то же самое, что
f(z=0, w=0, x=1, y=1)

Две звёздочки перед словарём означают: «каждую пару ключ-значение передай как именованный аргумент».

Поэтому порядок в def не важен: аргументы попадают по именам, а не по местам. f(z=0, w=0, x=1, y=1) и f(x=1, y=1, z=0, w=0) — один и тот же вызов.
Одна звёздочка вместо двух — f(*d) — тихая беда: словарь перебирается по ключам, и в функцию уйдут буквы вместо чисел. Программа не упадёт, а ответ будет мусорный.

Собираем проверку гипотезы

table = [(0, 0, 1, 1), (0, 0, 1, 0), (0, 1, 1, 1)]
res   = [1, 0, 0]

# значения функции для всех строк при гипотезе p
[f(**dict(zip(p, row))) for row in table]

Список сравниваем с res — столбцом F из условия. Совпал во всех строках — гипотеза верна.

if [f(**dict(zip(p, row))) for row in table] == res:
    print(*p, sep='')

*p разворачивает кортеж, sep='' убирает пробелы между буквами — ответ печатается сразу в нужном виде.

Решение целиком

from itertools import permutations

def f(x, y, z, w):
    return ((x <= y) or (z == x)) and (w <= z)

table = [(0, 0, 1, 1), (0, 0, 1, 0), (0, 1, 1, 1)]
res = [1, 0, 0]

for p in permutations('xyzw'):
    if [f(**dict(zip(p, row))) for row in table] == res:
        print(*p, sep='')

zwxy
Меняется от задачи к задаче только три строки: функция, table и res. Остальное переносится без правок.

Импликация — это <=

ABA → BA ≤ B
0011
0111
1000
1111

Весь перевод

¬A → not A
A ∧ B → A and B
A ∨ B → A or B
A → B → A <= B
A ≡ B → A == B

Скобки ставим везде. not x <= y Python читает как not (x <= y), а x <= y == z — вообще как цепочку сравнений. Лишние скобки не мешают, пропущенные — меняют смысл.

Если в таблице
есть пропуски

Демоверсия 2024, базовый уровень.

F = (x ∧ ¬y) ∨ (y ≡ z) ∨ ¬w

????F
000
1000
1010

Пустых клеток четыре. Значит и заполнений — 2⁴ = 16.

Пропуски перебирает product

from itertools import *

for a1, a2, a3, a4 in product([0, 1], repeat=4):
    table = [(a1, a2, 0, 0), (1, 0, a3, 0), (1, 0, 1, a4)]
    if len(table) == len(set(table)):
        for p in permutations('xyzw'):
            if [f(**dict(zip(p, row))) for row in table] == [0, 0, 0]:
                print(*p, sep='')

wzyx
product([0, 1], repeat=4) — все 16 наборов из нулей и единиц. Пропуски просто становятся переменными цикла.

Строчка, о которой забывают

    if len(table) == len(set(table)):
        for p in permutations('xyzw'):
            ...

В условии сказано: строки фрагмента различны. Заполнив пропуски наугад, можно получить две одинаковые строки — с таким вариантом дальше работать нельзя, перестановки для него не перебираем.

set(table) — множество, повторы в нём схлопываются. Длины разошлись — значит повтор был.

Без этой проверки ответов часто оказывается несколько, и задание «не решается». Условие про различные строки — не украшение, а рабочее ограничение наравне с самой функцией.

Спрашивают не буквы, а количество

F = x → (y ∧ z). Фрагмент содержит неповторяющиеся наборы аргументов. Вопрос: сколько существует различных способов расстановки переменных, подходящих для этой таблицы?

???F
0100
1100
ps = set()
for p in permutations('xyz'):
    if [f(**dict(zip(p, row))) for row in table] == res:
        ps.add(p)
print(len(ps))

2

Всё то же самое: вместо print — накопление в множество. Множество нужно потому, что при переборе пропусков одна и та же расстановка может подойти несколько раз.

Где здесь ошибаются

ОшибкаЧто получится
x < y вместо x <= y импликация становится неверной при x = y = 1
f(*d) вместо f(**d) в функцию уходят буквы, программа врёт молча
zip(row, p) ключами словаря становятся числа — ошибка при вызове
забыть set(table) лишние ответы там, где ответ один
from itertools import * забыт NameError: permutations не определено

А вот print(p) вместо print(*p, sep='') ошибкой не считается: ответ вы всё равно вписываете руками, и кортеж на экране читается не хуже.

Шаблон: держите под рукой

from itertools import *

def f(x, y, z, w):
    return ...              # выражение F: → это <=, ≡ это ==

res = [0, 0, 0]             # столбец F

for a1, a2, a3 in product([0, 1], repeat=3):
    table = [(a1, 0, 1, a2), (1, 1, a3, 0), (0, 1, 1, 1)]
    if len(table) == len(set(table)):
        for p in permutations('xyzw'):
            if [f(**dict(zip(p, row))) for row in table] == res:
                print(*p, sep='')

Столько же строк решает и задачу без пропусков: тогда table записывается сразу, а внешний for и проверка на повторы не нужны.
