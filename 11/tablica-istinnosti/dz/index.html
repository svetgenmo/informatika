Домашняя работа: задание 2 ЕГЭ

11 класс, углублённый уровень. Таблицы истинности программным методом: permutations, zip, dict, **.

Зачем это
Домашняя работа не обязательна — она поднимает оценку. Насколько, зависит от того, сколько типов закрыто.
Как устроено
Шесть типов задач. Тип закрывается двумя верными ответами подряд: ошибся — серия обнуляется, и тип придётся закрывать заново на новых числах. Задачи не кончаются.
Чем решать
Написанная один раз программа решает любое число вариантов — в этом и смысл метода. Первые четыре типа проверяют, понимаешь ли ты, что именно она делает; их считают в голове.
Как сдать
Закроешь хотя бы четыре типа — появится код работы и кнопка «Сдать работу»: впишешь фамилию и класс, форма откроется с уже подставленным кодом. Переписывать его руками не надо.
Учти
В начале следующего занятия будет проверочная на этих же типах. Так что задача не «получить код», а научиться — расхождение видно сразу.
Шаблон решения 
from itertools import permutations, product

def f(x, y, z, w):
    return ...          # выражение F: → это <=, ≡ это ==

table = [(0, 0, 1, 1), (0, 0, 1, 0), (0, 1, 1, 1)]   # строки фрагмента
res = [1, 0, 0]                                       # столбец F

for p in permutations('xyzw'):
    if [f(**dict(zip(p, row))) for row in table] == res:
        print(*p, sep='')

С пропусками таблица собирается внутри for a1, a2, a3 in product([0, 1], repeat=3), а варианты с повторяющимися строками пропускаются: if len(table) != len(set(table)): continue.
