Черепаха и turtle: перевод один в один

ЧерепахаPython
Вперёд nforward(n)
Назад nbackward(n)
Направо mright(m)
Налево mleft(m)
Поднять хвостpenup()
Опустить хвостpendown()
Повтори k [ … ]for i in range(k):

Две поправки. turtle в начале смотрит вправо, а Черепаха вверх — значит первой строкой setheading(90). Где Черепаха сейчас, говорят xcor() и ycor(); их и собираем.

Каркас: рамка фигуры

from turtle import *

mnx = 0
mxx = 0
mny = 0
mxy = 0

def sbros():                 # начать рамку с текущей точки
    global mnx, mxx, mny, mxy
    mnx = round(xcor())
    mxx = mnx
    mny = round(ycor())
    mxy = mny

def metka():                 # растянуть рамку до текущей точки
    global mnx, mxx, mny, mxy
    x = round(xcor())
    y = round(ycor())
    mnx = min(mnx, x)
    mxx = max(mxx, x)
    mny = min(mny, y)
    mxy = max(mxy, y)

speed(0)
setheading(90)

sbros() ставится перед фигурой, metka() — после каждого forward и backward. Закончили фигуру — переписали границы в свои переменные: ax1 = mnx, ax2 = mxx, ay1 = mny, ay2 = mxy. Перед второй фигурой sbros() ещё раз. round нужен потому, что turtle считает через синусы и вместо 30 бывает 29.999999999999996.

Пересечение двух рамок

lx = max(ax1, bx1)           # левая граница
rx = min(ax2, bx2)           # правая
ny = max(ay1, by1)           # нижняя
vy = min(ay2, by2)           # верхняя

Что писать под вопрос

СпрашиваютЧто писать
целые точки, с границей (rx - lx + 1) * (vy - ny + 1)
площадь(rx - lx) * (vy - ny)
периметр2 * ((rx - lx) + (vy - ny))
точки без границы (rx - lx - 1) * (vy - ny - 1)
объединение посчитать обе фигуры и вычесть пересечение: a + b - c

Точек по оси всегда на одну больше, чем длина: от 0 до 3 — это четыре точки, а длина три. Отсюда и «плюс один».

Когда фигура не прямоугольник

Если фигура одна и у неё есть выемка — рамка не поможет: разбей её на два прямоугольника, сосчитай точки строго внутри каждого и добавь точки на их общей стороне (для фигуры они внутренние). Чтобы увидеть вершины, печатай round(xcor()) и round(ycor()) после каждого шага.

Если в алгоритме повороты на 135 и 45 — фигура наклонная, вершины нецелые, и просят площадь. Тогда запоминай координаты четырёх вершин и считай площадь двумя треугольниками: abs((bx-ax)*(cy-ay) - (cx-ax)*(by-ay)) / 2.

Три ловушки

  • Нечётное «Повтори» — рамка обходится за два повтора, поэтому при нечётном числе Черепаха остаётся в противоположном углу и смотрит вниз. Переход ко второй фигуре считается оттуда;
  • Назад и Налево 270 — та же рамка, записанная иначе. Переписывай команды как есть, разбираться руками не нужно;
  • «плюс один» — точки и площадь отличаются ровно на него.
