Перебор слов и чисел

Задание 8 ЕГЭ: сколько слов и чисел подходит и под каким номером слово стоит в списке

Каркас: перебрать все слова

from itertools import *
n = 0                                  # номер слова в списке
for w in product('АЕКНТЦ', repeat=5):  # буквы ПО АЛФАВИТУ
    w = ''.join(w)                     # ('А','А','К',...) -> 'ААК..'
    n += 1
    if n % 2 == 0 and w[0] not in 'АЕК' and w.count('Т') >= 1:
        print(n)                       # первое подходящее
        break

product(буквы, repeat=5) выдаёт все слова длины 5 ровно в том порядке, в каком они стоят в алфавитном списке, — если сами буквы в строке записаны по алфавиту. В условии они почти всегда идут вразнобой (из слова), и переписать их как есть — главная ошибка задания.

номер последнего подходящегоlast = n, после цикла print(last)

(не) оканчивается цифрами 2 или 6w[-1] in '26' / w[-1] not in '26'

что-то про соседние цифрыфлаг ok и проход по парам w[i], w[i + 1]

(второй способ — замена)		 в копии: s = w, for c in '135': s = s.replace(c, '1'), потом s.count('01') == 0 and s.count('10') == 0; две чётные рядом — чётные в '0' и s.count('00') == 0

Пять ловушек

  • Буквы не по алфавиту. Начало списка в условии подсказывает порядок: сверь с ним первые строки своего перебора;
  • Номера с единицы. n += 1 стоит до проверки, иначе первое слово получит номер 0;
  • Ноль впереди. «Пятизначное число» не начинается с нуля, а product такие слова выдаёт;
  • Чётность номера. Условие на номер — это n % 2, а не последняя буква и не число подходящих;
  • Первое или последнее. Первое — break сразу, последнее — запомнить и дождаться конца цикла.
